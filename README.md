# UmbraCore Engine 🌑 (WIP)

UmbraCore é uma game engine customizada desenvolvida em C++ utilizando OpenGL. Este projeto está sendo construído como um Trabalho de Conclusão de Curso (TCC), com o objetivo de criar uma arquitetura base robusta para o desenvolvimento de jogos.
**💡Sendo seu principal diferencial** futuras ferramentas nativas para facilitar o desenvolvimento de jogos com cenários gerados proceduralmente.

## ⚠️ Status do Projeto
**Em desenvolvimento ativo (Work in Progress).** A arquitetura e os sistemas principais (Core) estão sendo estruturados e implementados no momento.

## 🛠️ Tecnologias e Dependências
* **Linguagem:** C++
* **API Gráfica:** OpenGL
* **Matemática Vetorial:** GLM (OpenGL Mathematics) - *Incluso no repositório (`thirdparty/`)*
* **Build System:** CMake
* **IDE Recomendada:** Visual Studio 2022 (com suporte a C++ e CMake instalado)

## ✨ Funcionalidades Implementadas
* Estrutura de Cenas (Scene System).
* Arquitetura de Componentes para os Objetos de Jogo (via geração de IDs estáticos).
* Renderização base via OpenGL.

## 🚀 Como Rodar o Projeto (Build)

O projeto foi configurado para ser compilado facilmente utilizando a integração nativa do Visual Studio com o CMake.
